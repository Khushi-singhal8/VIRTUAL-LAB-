## 🚀 What is this?

Traditional manufacturing labs have a problem: heavy machinery, safety risks, limited access, and zero automated feedback. We built **Virtual Manufacturing Lab** to fix all of that.

Students can now:
- 🧪 Perform complex manufacturing experiments **entirely in the browser**
- 🔁 Repeat experiments **infinitely at zero cost**
- ✅ Get **real-time automated feedback** and performance evaluation
- 📖 Follow a **structured 5-stage learning scaffold** from theory to result
- 🛡️ Practice **high-risk operations** (like gas welding) safely in a digital environment

| Feature | Description |

| 🎮 **Interactive 3D Simulations** | Real-time, physics-accurate 3D environments — not static 2D diagrams |
| 📋 **Step-by-Step Scaffolding** | Dynamic guided instructions prevent students from skipping critical steps |
| 🤖 **Automated Assessment** | Built-in quizzes and result evaluation with instant feedback |
| 🌐 **Zero Installation** | Runs entirely in the browser — no downloads, no setup |
| ♾️ **Infinite Repeatability** | Students can fail safely, learn, and retry endlessly |

## 🧪 The 9 Experiments

The platform covers **9 fully simulated manufacturing experiments** across 4 engineering domains:

### 📏 Measurement
- Vernier Caliper Experiment
- Micrometer Screw Gauge

### 🔥 Thermal Gas Joining
- Oxy-Acetylene Welding
- Brazing Process

### ⚡ Advanced Arc Joining
- TIG Welding
- MIG Welding

### 🪵 Forming
- Wooden Pattern Making
- Bending Test

### 🛡️ Special Module
- **Gas Welding Apparatus Familiarization** — safely digitizes high-risk lab setup; students achieve full apparatus familiarization without physical danger or material waste

## 🏗️ Technical Architecture

Built on a **3-Layer Simulation Architecture** for scalability, accuracy, and usability:

```
┌──────────────────────────────────────────────────────────┐
│  Layer 3: User Interface                                 │
│  HTML5 · CSS3 · JavaScript · Web Animation Libraries    │
│  Zero-install browser access across all devices         │
├──────────────────────────────────────────────────────────┤
│  Layer 2: Logic & Processing                             │
│  JavaScript · Physics Engine · Animation Logic          │
│  Real-time feedback · Interactive controls              │
├──────────────────────────────────────────────────────────┤
│  Layer 1: Engineering Foundation                         │
│  SolidWorks · Fusion 360 · CAD Modeling                 │
│  Standard lab procedures · Measurement principles       │
└──────────────────────────────────────────────────────────┘
```

## 📚 The 5-Stage Pedagogical Pipeline

Every experiment follows a structured scaffold guiding students from memorization to application:

```
🎯 AIM → 📖 THEORY → 🔧 PROCEDURE → 🖥️ SIMULATION → 📊 RESULT & OBSERVATION
```

| Stage | Purpose |
|---|---|
| **Aim** | Defines the core learning objective and engineering constraint |
| **Theory** | Establishes foundational equations and conceptual frameworks |
| **Procedure** | Maps the precise, step-by-step physical operations required |
| **Simulation** | Interactive, physics-accurate 3D sandbox for hands-on execution |
| **Result & Observation** | Automated evaluation with analytical feedback |
